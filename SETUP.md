# Cubeville: вход и мультиплеер для детей

Игра одна, работает в двух режимах:

| Где | Вход | Мультиплеер | Для кого |
|---|---|---|---|
| Артефакт в Claude | аккаунт claude.ai | все, кто открыл страницу одновременно | ты и взрослые тестировщики |
| Свой сайт + Supabase | ник из слов и секрет из 4 картинок | общий мир через Supabase Realtime | дети |

Пока `site/config.js` пустой, сайт работает офлайн, как раньше.

## Что видит ребёнок
- **Новый игрок:** выбирает ник стрелками (например, «Храбрый Енот 42») и дважды нажимает свой секрет из 4 картинок. Почту, телефон и настоящее имя не спрашиваем.
- **Вход:** тот же ник и те же 4 картинки. Прогресс подтягивается на любом устройстве: монеты, питомцы, одежда, дом.
- **Мир:** другие игроки видны в той же игре или локации. Счётчик 🟢 показывает, сколько людей онлайн.
- **Общение:** как и раньше, только смайлики и стикеры.
- **Для родителей (🛡️):** «Выйти из игрока» и «Удалить игрока» (стирает всё на сервере).

## Шаг 1. Проект Supabase (10 минут)
1. supabase.com → **New project**: имя `cubeville`, регион ближе к игрокам (например, Frankfurt).
2. **SQL Editor** → вставь файл `supabase/init.sql` целиком → **Run**. Должно быть «Success».
3. **Project Settings → API**: скопируй **Project URL** и ключ **anon public**. Ключ `service_role` никуда не вставляй.

## Шаг 2. Настройки входа (5 минут)
**Authentication → Sign In / Providers → Email:**
- **Enable Email provider** — включить: под капотом вход идёт через служебный адрес вида `p3x7x42@kids.cubeville.app`, писем на него никто не получает;
- **Confirm email** — **выключить**;
- **Secure email change** — выключить.

**Authentication → Rate Limits:** «Sign-ups and sign-ins» оставь по умолчанию. Лимит защищает секрет из картинок от подбора: вариантов 16⁴ = 65 536, плюс сервер ограничивает число попыток с одного адреса.

## Шаг 3. Realtime (2 минуты)
**Realtime → Settings:** выключи **Allow public access**. Тогда в канал мира `cv-world` могут войти только вошедшие игроки (правила заданы в `init.sql`).

**Лимиты бесплатного тарифа:** 200 одновременных подключений и 100 сообщений в секунду. Каждый игрок отправляет 6 обновлений в секунду, так что это примерно 15 игроков, которые бегают одновременно. Если будет больше, переходи на Pro или попроси меня разнести игроков по комнатам-сценам.

## Шаг 4. Ключи и выкладка сайта (10 минут)
1. Открой `site/config.js` и впиши ключи:
   ```js
   window.CUBEVILLE_CONFIG={url:"https://ТВОЙ-ПРОЕКТ.supabase.co",anonKey:"eyJ..."};
   ```
2. Выложи папку `site/` на любой статический хостинг:
   - **Netlify** — перетащи папку на app.netlify.com/drop;
   - **Cloudflare Pages** или **GitHub Pages** тоже подойдут.
3. После каждого изменения игры собирай сайт заново: `python3 build_site.py`. Скрипт берёт `index.html` (артефакт) и добавляет supabase-js и `config.js`.

## Шаг 5. Проверка (5 минут)
- [ ] Открой сайт → «Я новенький» → выбери ник → дважды введи секрет → ты в мире.
- [ ] Открой сайт на втором устройстве → «Войти» тем же ником и картинками → монеты и одежда те же.
- [ ] Неверные картинки → сообщение «Имя или картинки не подходят».
- [ ] Два устройства в одной локации видят друг друга, смайлики доходят, счётчик 🟢 показывает 2.
- [ ] 🛡️ → «Удалить игрока» → в **Table Editor → profiles** строки больше нет.

## Как это устроено
- **Таблица `profiles`:** номера слов ника, сохранение в JSON (до 20 КБ). Каждый видит и меняет только свою строку (Row Level Security). Ник после регистрации поменять нельзя, повторы ника запрещены.
- **Функции:** `nick_taken` проверяет, занят ли ник, не раскрывая чужие данные; `delete_my_account` удаляет аккаунт вместе со всеми данными.
- **Канал `cv-world`:** приватный, только для вошедших. Игроки шлют туда позицию, образ и номер смайлика.
- **Безопасность по протоколу:** по сети ходят только номера и значения из разрешённых списков:
  - ник — это номера слов из встроенных списков;
  - смайлики — номера из готового набора;
  - одежда и цвета — только из каталога и палитры.

  Получатель заново собирает всё из своих списков. Текст или HTML от другого игрока никогда не попадает на экран.

**Проверено:**
- SQL на PostgreSQL (PGlite), 15 проверок: правила доступа, повтор ника, блокировка ника, удаление, лимит размера.
- Два игрока через двойник сервера: видят друг друга, смайлики, разные локации, уход игрока.
- Попытки подделки данных: неверный ник, HTML в одежде, загрязнение прототипа.
- Регистрация, вход, неверный секрет, занятый ник, облако на втором устройстве — на двойнике Supabase.
- Сайт с настоящей supabase-js 2.45.4: правильные запросы входа, профиль из облака, подключение к Realtime.
