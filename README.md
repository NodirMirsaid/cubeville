# Cubeville

Безопасный кубический мир для детей 8–12 лет: 10 мини-игр, ролевой Городок, гардероб, общение только смайликами и стикерами.

**Играть:** https://nodirmirsaid.github.io/cubeville/

- `index.html` — собранный сайт (из `game.html` скриптом `build_site.py`).
- `config.js` — ключи Supabase для входа и мультиплеера; пустой = офлайн.
- `SETUP.md` и `supabase/init.sql` — как включить вход и мультиплеер.
